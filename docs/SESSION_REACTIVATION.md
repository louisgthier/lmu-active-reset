# Explicit session reactivation

The first activation still requires a fresh LMU process launched by this Sector instance. When the worker finishes, it may offer **Reactivate Active Reset** only after a clean native shutdown receipt: the process is still alive, native status is stopped, no native error occurred, and every recorded original hook prologue was verified. A fatal error, EAC detection, app shutdown, missing receipt or nonzero worker exit cannot offer reactivation.

The receipt is issued after native shutdown and controller cleanup. Reactivation is an explicit click, never an automatic response to a new session. The previous checkpoint and pending requests are discarded. The click repeats process identity, selected installation, EAC and offline Practice admission checks. The new worker repeats compatibility checks and audits all resident modules and their restored hooks before loading a fresh uniquely named one-session host. Owner discovery and vehicle memory bindings are rebuilt. Existing command preparation, permission leases and acknowledgement checks remain in force.

The reactivation capability exists only in the Sector instance that owned the launch and is consumed once. It is lost on process exit or revocation without a clean receipt. A separate bounded desktop-restart handoff is described in CLEAN_DESKTOP_HANDOFF.md; it never reuses the old authorization. It does not clear the persistent modified-process journal. Old DLLs remain resident until LMU exits, so online play still requires a full game restart. Repeated sessions may retain additional resident DLL state; native unloading is not attempted.

Fixture tests cover clean stop, explicit activation, single use, checkpoint invalidation, wrong identity, EAC, ambiguous discovery, app restart, fatal shutdown and denied fresh admission. The isolated GUI preview checks the reactivation presentation without starting a worker. No live game, process injection or running installation is changed during these checks. Multi-session gameplay validation remains pending.
